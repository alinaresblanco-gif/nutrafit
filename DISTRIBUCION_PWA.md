## Que es esta version
Nutrafit se entrega como una PWA instalable. No hace falta pasar por tienda: se abre desde el navegador y se puede anadir a la pantalla de inicio como si fuera una app.

## Como instalar

### Android
1. Abrir la URL en Chrome.
2. Esperar a que cargue la pantalla principal.
3. Abrir el menu del navegador.
4. Elegir Instalar app o Anadir a pantalla de inicio.
5. Confirmar la instalacion.

### iPhone / iPad
1. Abrir la URL en Safari.
2. Pulsar el boton de compartir.
3. Elegir Anadir a pantalla de inicio.
4. Confirmar.

### Ordenador
1. Abrir la URL en Chrome o Edge.
2. Si aparece el icono de instalacion, aceptarlo.
3. Si no aparece, usar el menu del navegador y crear acceso directo o instalar la aplicacion web.

## Uso general
1. Entrar siempre desde la URL publica o desde el acceso directo instalado.
2. Navegar entre las vistas desde la pantalla principal.
3. Guardar cada dato despues de registrarlo para que quede en el historial.
4. Si una vista tarda en actualizarse, cerrar y volver a abrir la PWA.

## Instrucciones de uso por vista

### Diaria / planificador
Vista pensada para organizar la planificacion semanal. Se usa para preparar el reparto de comidas y tener una estructura clara del dia.

### Calcular creditos
Introduce los datos personales que pide la pantalla y pulsa guardar para que el sistema calcule y conserve el historico de creditos.

### Menu semanal
Sirve para repartir las comidas de la semana por dias y momentos. Es la vista de trabajo para crear o revisar el menu semanal completo.

### Creditos de mis alimentos
Se usa para registrar alimentos con sus macros y calcular sus creditos de forma manual o automatica. Desde aqui se puede pasar a Nuestra despensa.

### Nuestra despensa
Permite consultar el catalogo de alimentos guardados. Tiene buscador para localizar un alimento de forma rapida.

### Mi control de agua
Se usa para marcar los vasos de agua consumidos durante el dia. La pantalla muestra el progreso y guarda el historico.

### Mi actividad fisica
Permite registrar ejercicio diario con tiempo, distancia, pasos, desnivel y foto. Tambien da acceso al GPS en vivo cuando se necesita medir una ruta.

### GPS Tracker
Pantalla especifica para grabar una ruta en directo. Se usa para iniciar, pausar, reiniciar y terminar el recorrido con datos de distancia y velocidad media.

### Evolucion de peso
Sirve para anotar el peso en cada fecha y revisar la evolucion en grafica. Tambien muestra el IMC y el estado general del progreso.

### Mi libro de recetas
Pantalla para consultar recetas favoritas, buscar entre ellas y guardar nuevas recetas para uso posterior.

### Lista de compra
Vista para anadir productos a la compra, revisar los articulos pendientes y limpiar la lista cuando ya no haga falta.

## Recomendaciones para clientes
- Usar siempre la misma URL para evitar confusiones.
- Instalar la PWA en el telefono para abrirla mas rapido.
- Guardar los datos al terminar cada vista para que no se pierdan.
- Si se cambia de dispositivo, volver a abrir la URL y anadirla otra vez a la pantalla de inicio.
