# Nutrafit - Entrega para clientes

Hola. Esta es la version estable de Nutrafit lista para usar como PWA instalable.

URL publica actual:
https://alinaresblanco-gif.github.io/nutrafit/

## Lo que incluye
- Acceso directo desde navegador o icono instalado en el movil.
- Planificacion diaria y semanal.
- Control de creditos, agua, ejercicio, peso, recetas y despensa.
- Lista de compra y registro de actividad fisica.

## Como instalar
### Android
1. Abrir la URL en Chrome.
2. Esperar a que cargue la app.
3. Abrir el menu del navegador.
4. Elegir Instalar app o Anadir a pantalla de inicio.
5. Confirmar.

### iPhone / iPad
1. Abrir la URL en Safari.
2. Pulsar el boton de compartir.
3. Elegir Anadir a pantalla de inicio.
4. Confirmar.

## Uso recomendado
1. Abrir siempre desde la misma URL o desde el acceso directo instalado.
2. Guardar cada registro al terminar de usar una vista.
3. Revisar el historial cuando quieras consultar tu progreso.
4. Si el navegador no actualiza cambios, cerrar y volver a abrir la PWA.

## Vistas principales
- Diaria / planificador: organizar el dia y la semana.
- Calcular creditos: obtener el total segun genero, edad, peso y altura.
- Menu semanal: repartir comidas por dias y momentos.
- Creditos de mis alimentos: registrar alimentos y sus creditos.
- Nuestra despensa: consultar el catalogo de alimentos.
- Mi control de agua: registrar vasos de agua y ver el historial.
- Mi actividad fisica: guardar entrenamientos y capturas.
- GPS Tracker: grabar rutas en vivo.
- Evolucion de peso: seguir el progreso y el IMC.
- Mi libro de recetas: explorar y guardar recetas.
- Lista de compra: gestionar compras pendientes.
